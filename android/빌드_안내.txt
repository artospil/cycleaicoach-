Cycle AI Coach 안드로이드 앱 빌드 안내
=======================================

1. Android Studio 실행 → 첫 화면에서 [Open] → 압축을 푼 "CycleAICoach" 폴더 선택
   (처음 열 때 "Trust Project?" 가 나오면 Trust)
2. 오른쪽 아래 진행 표시줄의 Gradle Sync 가 끝날 때까지 기다림 (처음은 몇 분, 인터넷 필요)
   - "SDK Platform 35 가 없다"는 알림이 나오면 알림의 Install 링크를 눌러 설치
3. 위쪽 메뉴 Build → Build App Bundle(s) / APK(s) → Build APK(s)
   (메뉴 이름이 버전에 따라 "Generate App Bundles or APKs → Generate APKs" 일 수 있음)
4. 끝나면 오른쪽 아래 알림의 [locate] 를 누르면 파일이 열립니다:
   app\build\outputs\apk\debug\app-debug.apk
5. 이 .apk 를 휴대폰으로 옮겨 설치 (설치 시 "출처를 알 수 없는 앱 설치 허용" 필요)

※ 이렇게 만든 debug APK 는 테스트·개인 설치용입니다.
  플레이스토어에 올릴 때는 Build → Generate Signed App Bundle / APK 로
  서명 키를 만들어 .aab 파일을 만듭니다.

앱 구성
- 화면: app/src/main/assets/www/index.html (+ chuncheon_base.json, presets.json)
  → 앱 내용을 고치면 이 세 파일을 최신본으로 바꾼 뒤 다시 빌드
- 지도·계획 데이터는 앱 안에 들어 있어 오프라인에서도 동작
  (로고 글꼴만 인터넷 연결 시 원래 모양)
- 카카오맵·사진 원본 링크는 휴대폰 기본 브라우저로, 전화번호는 전화 앱으로 열림
- 가민 워크아웃 ZIP 은 휴대폰 "다운로드" 폴더에 저장
- 앱 이름: Cycle AI Coach / 패키지 이름: kr.coachinglabs.cycleaicoach
